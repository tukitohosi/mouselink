MouseLink 1.0.2 · Windows 与 iPad 共用键鼠

安装与打开
运行 MouseLink-1.0.2-Setup.exe，安装后双击桌面“MouseLink”图标。
也可以解压便携包，双击 MouseLink.exe；请保留同目录其他文件和 _internal 文件夹。
日常使用和刷写内置固件均无需安装 Python、Arduino 或 PlatformIO，软件不联网。
日常版使用混合鼠标逻辑，不限使用时长，无需开启 iPad 辅助触控。

准备
1. 用 USB 数据线连接 ESP32-C3 SuperMini 原生 USB 开发板（4 MB）。
2. 新开发板先点击“一键刷机”，按下文操作。
3. 在 iPad 蓝牙设置中连接 MouseLink-iPad。
4. 首次使用新开发板，用“检查光标位置”分别确认横屏和竖屏的七个位置。

两种切换方式
自由切换（推荐）：从 iPad 真正的最左边缘继续左推，返回电脑。
  卡片右下角“快捷键返回”开启后，也可按 Ctrl + 左 Alt 返回。
  全新安装默认关闭此开关；升级保留原来的模式行为。
锁定在 iPad：碰到边缘仍留在 iPad，用 Ctrl + 左 Alt 返回电脑。
停止桥接后可更换模式、开关和速度。

怎样往返
进入 iPad：把光标推到电脑最右边缘，稍停即可进入。
边缘返回：先移动到 iPad 真正的最左边缘，再继续向左推动。
边缘处需短暂等待定位确认；一次很快的大幅移动不会直接跳回电脑。
快捷返回：按下 Ctrl + 左 Alt，全部松开时返回。普通 Esc 仍发给 iPad。
紧急返回：Scroll Lock 或 Ctrl + Alt + Esc。
按住鼠标拖动时不会从边缘返回；松开后再继续左推即可。

一键刷机
支持：ESP32-C3 SuperMini 原生 USB 接口（4 MB），不包含 CH340/CP210x 转串口开发板。
点击“一键刷机”，选择设备，再点击“备份并刷入”。打开刷机页会停止键鼠桥并释放串口。
软件先检查固件和设备、备份并校验原固件，成功后才会写入。
已知兼容版本保留蓝牙配对；空白板或未知固件会完整初始化，覆盖原有内容。
写入、校验、重启和通信检查完成后，按提示连接 iPad 蓝牙。
刷机不会自动开启键鼠控制；开发板插入电脑也不会自动刷机。
多个开发板同时连接时必须明确选择一个；正常桥接请只连接一个。
无法进入下载模式：关闭占用串口的程序，按住 BOOT、轻按复位，松开 BOOT 后重试。
没有发现设备：检查数据线和 USB 口，点击“刷新设备”。
恢复：点击“恢复备份…”，选择软件生成的 backup.json。只允许恢复到同一块开发板，恢复前也会备份当前固件。
不要在刷写期间拔掉 USB。若请求关闭，软件会等待操作结束后退出。
写入校验通过但通信未恢复时，重新插拔 USB；恢复其他固件后可能没有 MouseLink 通信通道。

停止与关闭
关闭窗口、Alt+F4 或托盘“退出”都会停止桥接、释放键鼠及串口并退出。
未连接开发板或蓝牙也可以正常关闭；设置保存失败不会阻止退出。
刷机操作进行中关闭窗口，会显示等待状态，结束后自动关闭。

连接问题
iPad 蓝牙尚未连接：在 iPad 蓝牙设置中点一下 MouseLink-iPad。
完整初始化后需要重新配对：在 iPad 忽略旧设备后重新配对。
没有光标：保持 iPad 解锁，确认 MouseLink-iPad 蓝牙已连接，再用“检查光标位置”验证。
刷机或重新配对后仍无光标：可在 iPad 设置中关闭蓝牙，拔下开发板 USB 约 10 秒后重连，再打开蓝牙。
此操作曾恢复光标，但不代表已确定问题原因。

数据位置
设置和桥接日志：%LOCALAPPDATA%\MouseLink
固件备份：%LOCALAPPDATA%\MouseLink\firmware-backups
刷机日志：%LOCALAPPDATA%\MouseLink\flash-logs
升级和卸载默认保留这些数据。程序不自动开机启动。

定位固件的既有验证范围
iPad Pro M5 / iPadOS 26.6.1：横竖屏七点定位、左边缘返回和快捷返回已由用户确认。
本次回退后用户已确认进入 iPad、点击打开 App、左边缘返回均正常。
已知限制：底部持续下推偶尔无法调出 Dock，或 Dock 弹出后收起导致退出失败；请移回屏内后重试。
不承诺全部系统边缘手势与原生蓝牙鼠标完全一致；详见仓库中英说明。
